MINECRAFT

Minecraft, a really famous, liked and one of the most played games was released in 2009, April.
This is a sandbox game which uses blocks and non-real life physics. It is set in a blocky world where our main goal is to beat the Ender dragon.

This game is full of different creatures and some of them include
Villagers (The human-like creatures/NPCs of the game)
Iron Golems
Wolves/Dogs
Cats
And Many More...

The game has a lot of different modes and some of them include
Survival Mode (The main mode of the game)
Creative Mode
Adventure Mode
Hardcore Mode
And Many More...

The game has a lot of different biomes and some of them include
Plains
Forests
Oceans
Mountains
And Many More...

The game has a lot of different dimensions and some of them include
The Overworld
The Nether
The End
